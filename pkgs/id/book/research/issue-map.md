## How to work the map

Rank is a proposed order to investigate or reconcile. Each named, in-scope native or manually mapped text prerequisite precedes its dependent. Among eligible rows the ordering favors high-leverage program decisions, then independent work, ownership/review reconciliation, blocked work, parked work, and holds. Within these groups it favors `now`, repository priority and number of dependent issues. A prerequisite's position can keep its dependents further down the list. The issue title links the body supporting each text edge; [the native dependency endpoint](https://docs.github.com/en/rest/issues/issue-dependencies) supplies each native edge. Text links can identify a prerequisite that has already landed. Re-read it before declaring it an open blocker.
