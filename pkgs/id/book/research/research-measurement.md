# What the scale measurements establish and which experiment comes next

_Research snapshot of November 23, 2026. Code and issue observations refer to the cited revisions and collection times._

Can a node hold a large number of idle worlds, accept one more participant, render a fixed game view, and recover a durable write? These are four different workload questions. A pass on one neither pays for nor certifies the others. This chapter records the evidence already available and proposes bounded comparisons for the rest. Each proposed budget limits a future pilot. No benchmark, provider request, Fleet dispatch or physical-device run was performed for this chapter.

## Experimental design and the cost ceiling

Kalibera and Jones distinguish variation between measurements, process starts and builds. Estimate the dominant level before allocating repetitions. For a deterministic guest, establish semantic equivalence first and report exact fuel with guest/compiler/engine configuration. For timing, preserve per-operation observations and independent process identifiers, randomize or alternate condition order within the same machine class and report the spread. SPEC’s run rules contribute the discipline of declaring the workload, configuration and permissible comparisons. These pilots do not require a SPEC workload or license. [Kalibera and Jones, ISMM 2013](https://kar.kent.ac.uk/33611/) · [SPEC run and reporting rules](https://www.spec.org/cpu2017/docs/runrules.html)

Each pilot below has one primary comparison, a fixed upper bound and an independently checkable outcome. These caps are proposed experiment designs, not new program gates. Before any later dispatch, read quota and existing results on the authorized route, verify the selected host profile and reuse any matching completed measurement. Use an available GitHub-hosted plan allowance for eligible work. Keep named reference-laptop and physical-host evidence tied to their actual hosts. A runner timeout, unavailable host or missing browser is an environment result, not a system limit.

## Storage conformance, retained data and deployment

At the inspected main revision, the shared record-port fixture contains 25 vectors and the IndexedDB row remains reserved. The prior #10213 prototype reports Chromium conformance against that script and a separate reference model. Closing and reopening a database handle inside one process does not exercise browser restart, power loss, origin eviction or live provider behavior. The research edition recommends adopting the bounded request-batch profile. The recorded handoff at #9082 leaves the owning issue to decide the profile’s disposition. Evaluate conformance at the declared interface, then establish any stronger claim with a separately named test.
