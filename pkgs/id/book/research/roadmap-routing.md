## How to use a row

Start from the unchanged `rank` and `number`. Read `gate_display` and `status_display` before using `proposed_proof_or_decision`. A concrete proof describes what to evaluate after the authorized owner is known; a held or blocked item stays held. An empty assignee or PR array only describes the saved snapshot. A negative claim check needs fresh comments and PR reads before implementation or merge. Each row also includes a digest of the issue body used to route it.
