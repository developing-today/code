# Designs

Design records for this repo live in [`doc/`](../../doc/). This folder holds none. Each record is a folder named `<UTC datetime>_<kind>_<name>`, with the document inside it. [`doc/DOCUMENTATION_PROTOCOL.md`](../../doc/DOCUMENTATION_PROTOCOL.md) says when a record is needed, how to append updates to it, and what to do when a newer design replaces an older one.

This folder exists so that the three planning levels (roadmap, design, plan) are all visible from [`planning/`](../README.md). It holds no records of its own.

Use the [design record template](../templates/design.md) for the sections a record should cover. Link the record from the roadmap row it belongs to.
