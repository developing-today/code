================================================================================
KEY FEATURES
================================================================================

🎯 Mode System
   - Shadow mode (default): Discovery only, no mutations
   - Live mode: Full execution including session creation
   - Mode file: ~/.local/state/opencode-claimant/mode

📊 Four Queue Monitoring
   - repo-health-code-pilot
   - repo-health-opencode-pilot
   - repo-health-openchamber-pilot
   - repo-health-nix-pilot

🚦 36-Session Concurrency Cap
   - Monitored via OpenCode server API
   - Only root sessions without terminal markers count
   - Active window: 30 minutes
   - Fail-closed when server unreadable

🔄 Recovery Rules (#4758)
   - Zero-message recovery: Verify → Delete → Reclaim atomically
   - Gone-session recovery: Verify absence → Reclaim atomically
   - Exhausted attempts: Delete then fail task terminally

⚡ Atomic Operations
   - Bind operations use compare-and-clear (migration 0021)
   - Recovery operations use atomic bind with special launched_by values
   - Prevents double-binding and duplicate execution

📍 Session Location Verification (#4870)
   - Verify location.directory before binding
   - Delete misplaced sessions
   - Prevents session→repo attribution errors

🛡️ Hard Rules Compliance
   - Never work tasks directly (claim/bind/launch/record only)
   - No credentials in prompts/logs
   - No cap violations
   - No double-binding
   - Atomic operations
   - Session location verification
   - Task state verification

📝 Fire Logging
   - Logs to fires.jsonl
   - One JSON line per fire
   - Records: timestamp, mode, candidates, launched, cap_room, skips
