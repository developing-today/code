# Preserved conflicts and precedence

This is a design adjudication register, not a fresh ratification request. It makes competing source claims visible; it does not silently discard lower-precedence material. Requirement IDs are added when the curated register is authored.

## Precedence

Per the intake note and governing handoff: the handoff governs intake; for conflicts among specification documents, charter > full proposal > recovered original. The supplemental note is a candidate source and does not override the charter. The handoff requires reconciliation against current ratified policy, and recent code is evidence/collision context, not a scope limit.
