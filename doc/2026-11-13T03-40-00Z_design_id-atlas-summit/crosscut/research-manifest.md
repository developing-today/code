## Separate follow-up research work

- **Atlas chunk identity producer contract:** no checked-in production producer is present. Define producer boundary, exact bytes, normalization, profile/version, algorithm and independent known-answer oracle; do not infer from consumers, fixture strings or vector joins. This is an explicit contingent slice in `implementation-slices.json`, triggered before any cross-system Atlas identity interoperability claim.
- **Legacy artifact signature preimage mismatch:** compare implementation bytes with docs; create golden vectors from unmodified legacy serde serialization; decide only an explicit new profile for corrected domain-separated canonical encoding. Never modify old signed preimages or re-sign stored history in place.
- **Other issues:** key management/revocation detail, tenant policy, content reference-vs-copy, and hosted transport protocol remain owned by their component issues; this note only records the seams.
