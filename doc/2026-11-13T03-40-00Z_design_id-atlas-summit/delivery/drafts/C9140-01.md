## Problem and goal
Separate recommendation snapshots from search history and apply per-class retention/deletion policy. ParentSnapshotId hashes only the complete signed parent envelope of inputs, ranking configuration and cutoff; it excludes pages. Each page has an independently signed envelope and EnvelopeId; cursor binds parent SnapshotId plus position.
