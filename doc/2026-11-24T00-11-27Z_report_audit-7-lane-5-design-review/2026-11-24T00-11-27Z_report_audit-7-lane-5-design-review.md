1. Enumerate the design home; classify by the dated-record kind token (design/decision/architecture + undated `*design*` files + design subdirs).
2. Full-text structural pass per record: tracking refs, slice/phase/stage refs, dependency vocabulary, priority vocabulary, acceptance vocabulary, risk vocabulary, word count.
3. Hand-read every flag class completely (no-tracking-ref, multi-slice-without-dependency-vocabulary, thin) plus every major programme; heuristic flags are hypotheses, never verdicts — in this run 15 of 16 ordering flags were vocabulary misses.
4. Verify named tracking issues against the API; check whether the design of record is a doc/ record or only an issue body.
5. File class findings as single issues with full lists; file per-design findings as comments on the design's own tracking issue; verdicts for sound designs live in the ledger.
