# desktop-commander Worker (#13404). The self-hosted replacement for the
# vendor's metered Remote Desktop Commander relay: an OAuth-fronted MCP

#

===== pkgs/desktop-commander/worker/src/index.ts (behaviour, from full read) =====
Routes: /healthz -> {ok:true, service:"desktop-commander"};
/.well-known/oauth-protected-resource (+/mcp) and
/.well-known/oauth-authorization-server (public); /register POST only
(405 otherwise); /authorize GET/POST; /token POST only; any other path
404 {error:"not found"}; /mcp requires isAuthorizedMcpCaller (OAuth
access token valid, else constant-time compare with MACHINE_BEARER) ->
401 {error:"unauthorized"} + WWW-Authenticate: Bearer
resource_metadata="https://commander.security.cab/.well-known/oauth-protected-resource";
missing ACCESS_CLIENT_ID/SECRET -> 500 {error:"bridge credentials are
not configured"}; proxy: deletes host, authorization,
cf-access-jwt-assertion, cf-access-client-id, cf-access-client-secret;
sets CF-Access-Client-Id/Secret from env; target = BRIDGE_BASE + path +
search; response passed through untouched (status, headers incl.
Mcp-Session-Id, SSE body).
