# F03 — citation and occurrence resolution conformance fixtures

**Tier/status:** recommended; independently ready after design merge; live adapter conditional. Parent [#6020](https://github.com/developing-today/code/issues/6020), programme [#6018](https://github.com/developing-today/code/issues/6018); [design on main](https://github.com/developing-today/code/blob/main/doc/2026-11-11T03-45-00Z_design_atlas_v2_v4/2026-11-11T03-45-00Z_design_atlas_v2_v4.md). ## Scope and distinction

Build an offline, test-only conformance corpus plus reference resolver. Each synthetic record has a content ID, distinct occurrence ID, version, source coordinates, retained bytes/hash, coverage flag and rights; a request includes caller and current authorization. Output is an authorized source/version citation with an exact byte range or a properly scoped unavailable/not-found response. Completeness is only within the enumerated ingested, retained, permitted snapshot. Never reveal forbidden occurrence counts or paths.

This does **not** implement #3125's occurrence registry, backfill, CAS, storage, MCP tools or live resolution; #6035 owns span design and #6062 owns graph publication. #6266 is an independently scoped product. This fixture is an adapter-conformance oracle, not a new response wire protocol or production schema.

## Failing-first steps and oracle

1. Hand-author expected results for same bytes at multiple locations/rights, pinned historical version, source rename, missing coverage, deleted bytes and changed permissions. Begin with deliberately incorrect aliasing and stale-replay implementations and assert conformance rejects them.
2. Implement a simple independent reference projection over explicit fixture records. Model/property tests generate occurrences and ensure each successful citation resolves to the _exact retained bytes_ at its specified version/range; byte-identical IDs cannot merge occurrence authority. Current revocation makes old citations unavailable; a hidden insertion never changes visible counts or metadata.
3. Supply a test-local adapter interface and a small deliberately correct fake; compare fake and hand-authored expected results. Avoid importing F02's test helper so either slice can ship separately. F02 checks whole-pipeline noninterference; this issue checks occurrence identity and citation fidelity.

**Hard prerequisites:** merged design and test-local fixture only. **Soft ordering:** #3125, #6035, #6062 and #6054 deletion design; real adapter needs registry and current authorization/deletion behavior, and is explicitly out of scope.

**Candidate seam:** verified `pkgs/atlas-search/crates/atlas-core/src/types.rs` and existing `tests/`; add isolated `pkgs/atlas-search/crates/atlas-core/tests/citation_conformance.rs` without modifying production types. Proposed future command: `cargo test --manifest-path pkgs/atlas-search/Cargo.toml -p atlas-core --test citation_conformance`. No live corpus, credentials, network, or external cost.

**Risks:** a hash verifies bytes, not source truth; unavailable content cannot be regenerated as historical evidence. A test fake is not evidence the registry or resolver is deployed.
