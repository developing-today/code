## Source admission, publication and replay

Use a source-specific adapter with a scoped stable object ID, source revision, event kind, source cursor and reconciliation coverage. Persist an event before acknowledging delivery. A retry looks up the same event and its terminal or resumable state. A newer revision fences out older deliveries. Missing items become deletion candidates only after a complete authoritative inventory of the same scope, or a positive source deletion. Lost source access suspends serving for that scope.

| Adapter | Initial evidence and replay test |
|---|---|
| Queue, PM, quota and reports | Advance a monotonic row cursor or replay an overlapping page with a stable tie-breaker. Compare the final manifest to the source fixture after insertion, correction and deletion. Track each source watermark independently. |
| GitHub | Reuse the comment writer. Use repo/object IDs, commits and versioned file occurrences for the remaining object classes. Reconcile a missed webhook, renamed file and interrupted page. External corpus admission depends on the licence and zone policies. |
| Muse | Begin with an authorized provider export or documented local manifest. Require versioned thread/message/artifact references, explicit completeness and rights. A partial export cannot retire missing attachments. Provider capabilities and continuous access require separate evidence. |
| OpenCode | Restrict the adapter to approved visible part types. Compare close-event delivery with later reconciliation of the finalized session. Unrecognized or withheld parts do not enter ordinary staging. |
| ID | Consume typed object revisions and retractions. Tag projector origin and direction. Replaying an Atlas-originated publication must not introduce a second independent source occurrence or popularity event. |
| Memory, notes, reports and repo docs | Use the corpus registry and existing memory connector. Compare change detection and a complete tree inventory after a move, edit, identical-content copy and removal. Keep each occurrence's authorization and locator. |

The metadata check avoids fetching unchanged revisions. A content digest avoids reprocessing unchanged bytes. Parser, chunker, normalization and model fingerprints determine which derived data can be reused. A one-paragraph edit re-embeds every distinct embedding input it changes, including boundary-neighbor changes. An offset shift alone can create new occurrence spans while preserving the vector. Preserve the distinction between producer-specific legacy hashes and verified canonical SHA-256. Reuse the landed occurrence writer and source-root registry. [#9097](https://github.com/developing-today/code/issues/9097) · [#13216](https://github.com/developing-today/code/pull/13216) · [#13485](https://github.com/developing-today/code/pull/13485) · [#12301](https://github.com/developing-today/code/pull/12301)

Stage unclassified inputs within the restricted zone. Record classification and provenance before promotion. Bind an attestation to its inputs, gate outputs and publish generation. Failure leaves the previous serving generation intact. In a single metadata transaction retire a deleted occurrence, advance the scope's revocation epoch and enqueue idempotent cleanup. Check acknowledgements from CAS, FTS, dense and sparse indexes, recommendation materializations, result caches and replicas. A CAS object remains reachable through a different eligible occurrence while references remain. A restore must catch up tombstones before opening for reads. Distinguish access revocation from physical erasure and backup retention. [Ingest gate](https://github.com/developing-today/code/pull/11995) · [Attestations](https://github.com/developing-today/code/issues/6045)

## Retrieval experiment matrix

Freeze a baseline manifest with code SHA, corpus generation, approved scope, policy epoch, query set, judgment version, candidate budget, model artifact, dimensions, fusion constant, tie rule, cache state and runner. Use whole query sessions and near-duplicate document families as split units. A changed chunker also needs source-document judgments so ID churn does not masquerade as a quality regression. [Evaluation reconciliation](https://github.com/developing-today/code/pull/13327)

| Arm | Independent comparator | Release evidence |
|---|---|---|
| Routing and filter extraction | Synthetic explicit FilterSpec versus inferred filters, including inclusive dates and conflicting hints | Scope can only narrow. Measure warmed classifier p95 separately from retrieval. Target under 10 ms. Bound each strategy's fan-out. |
| Conversational rewriting | Original query and a context-limited rewrite on the same authorized history | Class-sliced Recall@k and no-answer errors. Preserve original query provenance. Evaluate HyDE, decomposition, expansion, step-back and multi-query as separate arms only where each has a hypothesis. |
| Snowflake 256d and native ANN | Eligible exact 768d cosine, then renormalized 256d exact to isolate truncation from graph loss | Eligible-neighbor overlap, judged Recall@100, end-to-end p95, index bytes and build/update cost. A mixed-scope top-k followed by row filtering can starve the eligible pool. Use eligible partitions or exact restricted scan. |
| SPLADE, ColBERT and BGE-M3 | Fixed dense/lexical baseline; separate sparse-only, late-interaction and combined arms | Additional relevant documents in the union, per-corpus recall and cost. Measure token index growth. Keep model identities disjoint and shadow the challenger until a cutover verdict. |
| Cross-encoder | Same fused list before and after local reranking at 50, 100 and 200 candidates | Report paired nDCG@10/MRR@10, query slice sizes and warm/cold p95. Check CPU/runtime capability on deployment hardware. Disable losing corpus/strategy arms. |
| Feedback | Independent relevance judgments plus eligible exposures, with position and result-list version | Compare clicked, skipped and failed sessions; clicks alone confound relevance with presentation. Record abstentions and judgment coverage. |

The shipped and historical evaluation configurations use different RRF constants and branch depths. Reproduce each configuration before attributing a difference to a model. The 54 near-exact queries already judged the Jaccard stage. Use them as a regression slice and reserve independent fresh queries for the final promotion decision. Publish synthetic fixtures and approved aggregates. Private query traces and restricted passages stay in their permitted zone. Hosted comparison requires explicit eligible inputs and plan headroom. ## Interfaces and recommendation acceptance

Send the same synthetic request through CLI, REST and MCP. Authenticate each harness, intersect caller grants and destination restrictions and authorize each branch, detail read and neighboring span. If a forbidden exact match can push an eligible item out of a fixed pool, filtering the rendered envelope cannot restore that item. Test the intermediate candidate IDs as well as final output. Cache by authorized scope, index generation, retrieval parameters and policy epoch. Bound the residency of stale values independently of invalidating reads. Treat the per-query Worker cache and flag-controlled D1 result cache as separate paths. [Search core](https://github.com/developing-today/code/blob/fbdc85357b8a4e1941a3ef5445a136fbde444229/pkgs/atlas-search/crates/atlas-core/src/search.rs#L308-L406) · [Worker MCP](https://github.com/developing-today/code/blob/fbdc85357b8a4e1941a3ef5445a136fbde444229/pkgs/atlas-search/worker/src/mcp.ts#L105-L122)

For Fleet, record which generation each batch or offline replica can answer. A replica with an expired authorization lease refuses a narrowed or revoked scope. Verify engine compatibility before copying a permitted vector index. For ID, test both a versioned Atlas-to-ID publication and independent ID-to-Atlas ingestion. Verify that a repeated projection preserves identity, tombstones retire a result, and a synthetic ID query returns a resolvable authorized occurrence. [Replica decision](https://github.com/developing-today/code/pull/12868) · [Publication format](https://github.com/developing-today/code/pull/7998) · [Inbound pipeline](https://github.com/developing-today/code/issues/10171)

For the recommender, generate eligible candidates from a decaying profile centroid, per-session co-occurrence, recency and provenance-neighbor links. Log the source of each candidate in the private evaluation record. Compare with recency-only and content-only baselines, report repeated exposures, diversity and time-split relevance. Rank and diversify the union before freezing the parent snapshot. Paging and durable accumulation already exist. Test cursor binding, retries, restart and reauthorization after deletion independently of candidate quality. Production binding and activation need their own evidence. [Paging](https://github.com/developing-today/code/pull/12873) · [Accumulator](https://github.com/developing-today/code/pull/13353)

## Promotion and rollback

Record a failed or inconclusive experiment with the same provenance as a win. Keep the current serving manifest until the measured arm passes its predeclared gates. Switch via a versioned serving pointer so the previous compatible index can be restored with the current revocation floor. An engine or source change updates the relevant book reference and verification receipt in the same change. The physical disposition of mixed stores, multi-client product direction and thinking-trace inclusion remain explicit program decisions. Gmail remains paused.
