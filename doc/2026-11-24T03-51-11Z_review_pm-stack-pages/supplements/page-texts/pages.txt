Overview — The stack front door (#1134): needs-you, projects, quotas, and health at a glance.
Today — The day's top objectives + per-project momentum.
Digest — The scheduled PM digest (#1278): moved / blocked / needs Drew / done / quota outlook from the canonical projection, archived per day at /digest?date=<date>.
Needs you — NEEDS USER vs NEEDS ORCHESTRATOR, and every live session.
Decision sets — Every raised decision set (#8867): new today, this week, or all — with open-question counts. Each row opens the set's own page.
Board — The curated cross-repo WIP board.
Roadmap — The program roadmap at every grain.
Reports — Review report versions and resolve prose conflicts without overwriting stored text.
Source conflicts — One read-only queue of every live source disagreement, with both values and its age.
Sessions — The agent/session identity registry: who ran what, tokens, task links.
Search — Search board, roadmap, registry sessions, DNS, services, and tier items by title or linked issue/PR ref.
Events — The cross-stack chronological stream of dashboard actions, orchestration publishes, and session outcomes.
Comments queue — Dashboard comments still waiting on a loop (#1210): messages awaiting triage and GitHub comments pending or failed to post, with kind/state counts and each failed item's last error.
Program status — The projects hub: every project's status, roadmap, and tracked work, one page per project under /program/<id> — fed from the project registry, the tracked issues, and the Project pool.
Queue — In progress, blocked, recently completed, and next-up work across projects.
Usage & billing — Token quotas, PAYG dollars, and every SaaS service's usage vs its limits.
DNS register — Every domain: next renewal, unused, earmarked. (#902's register)
Cost Explorer — Two tabs over the fleet's cost data: AA Explorer (Artificial Analysis measurements, frontier charts, plan/API/per-task efficiency) and Model Explorer (every model in the fleet's catalogs, its pool seats, plan, and measured value).
Health — Service & page health (#1147): live probes for every stack service, feed section ages, last job runs, this dashboard's render history — and the services & ports topology (#1137).
Alerts — The alert throat (#3676): sentinel incidents, Web Push delivery + one escalation, ack/close, the Turso ledger.
Notifications — Notification measurement (#3319): the weekly sent-vs-acted-on roll-up over the alert throat's send ledger, with display-only default-off proposals under 10%.
All pages — This manifest as a page — every registered view in one place.
