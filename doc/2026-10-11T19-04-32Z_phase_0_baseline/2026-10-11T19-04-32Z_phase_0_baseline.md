## Review (end of phase, whole diff 90efcb24 to HEAD)

A separate review branch (`review-phase-0`) read the whole phase diff and proposed fixes with tests. Each fix has a red test first. Confirmed fixes:
- the toolchain pin check reads quoted, commented and comment-only bindings, and ignores comments in code; README and WEB name the pinned version;
- output_within bounds the wait for its pipe readers, even when a grandchild keeps them open;
- unix stop keeps its cfg gate and allow, and unsafe blocks carry an allow;
- the startup wait ends at its deadline even while a chatty server keeps sending lines;
- ArtifactLog::insert refuses an artifact that one frame cannot carry, as Forbidden, before any state changes; opening a log replays its lines without that check;
- the tuple properties draw pairs where one value extends the other;
- a page is as full as the budget allows, and the pull refuses an over-budget page and accepts one oversized artifact alone;
- lint fixes in the new tests.
