# Cloudflare Workers Paid — Pricing, Included Allowances, Hard Limits & Recent Changes

**Research date:** 2026-10-20
**Plan in scope:** Workers Paid — $5 USD / month minimum per account, Standard usage model
**Method:** Official Cloudflare sources first — Workers pricing page (updated 2026-10-02 on the page), Workers limits page (updated 2026-10-12 on the page), product pricing / limits pages, Cloudflare Changelog, and Cloudflare Blog. Every price / number below carries its source URL. Anything not found on an official page is marked **UNVERIFIED** — do not budget on UNVERIFIED rows.
**Key framing:** $5 is a _minimum / subscription_, not a cap. Almost every product below is metered: you stay at $5 only while total use stays inside _all_ of the included allowances at once. A single meter running over (e.g. Durable Object duration, KV writes, Browser Rendering hours, Containers) adds to the bill on top of $5.

Primary sources used throughout:

- Workers pricing: https://developers.cloudflare.com/workers/platform/pricing/
- Workers limits: https://developers.cloudflare.com/workers/platform/limits/
- Changelog index: https://developers.cloudflare.com/changelog/

## 4. Staying at exactly $5 — the meters that break it first (summary for a solo dev)

1. **Durable Object duration** — 400k GB-s sounds large; one non-hibernating Object eats most of it. (§1.7)
2. **KV writes / deletes / lists at $5/M** — 10× reads. (§1.4)
3. **D1 / DO-SQLite rows written at $1/M** — 1,000× rows read; indexes add writes. (§1.5, §1.7)
4. **Browser Run hours at $0.09/h after only 10 h** + $2/extra concurrent browser. (§1.13)
5. **Containers** — only 25 GiB-h memory / 375 vCPU-min included, plus _metered egress_ unlike everything else. (§1.14)
6. **Workers AI Neurons** — only 10k/day free, same as Free plan. (§1.12)
7. **Logs** — 20M events, then $0.60/M today; GB-based from 2026-12-01. (§1.3)
8. **Workflows steps** — newly metered from 2026-08-10. (§1.9)

Set a **budget alert** (available in product sidebars since 2026-06-04) before deploying anything stateful.
