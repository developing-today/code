## Method notes

- Every merged-PR number in the census is a `total_count` from one GitHub Search query of the form `repo:<repo> is:pr is:merged merged:<range>` with `per_page=1`.
- Daily-note evidence was extracted by heading scan, filtering out the repetitive cron headings (nix-mcpx 15-minute checks, sandbox-boot-init, marketplace sweeps, laptop-channel-heal, stewardship cycles) and then keyword-filtering for completion/merge/launch headings; the extract is in `memory-completion-extracts.md`.
- Where a book and a primary source disagreed, the primary source was used and the disagreement recorded in the census report's final section.
