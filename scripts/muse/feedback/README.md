# Muse enrollment feedback records

When a bootstrap, enrollment, or handoff operation fails or needs a code fix,
copy `TEMPLATE.md` to `YYYY-MM-DD-<agent-name>.md` and record the exact
non-secret evidence and recovery. This record is part of the handoff: do not
leave failure details only in chat.

Never include BWS or 1Password values, claim URLs, claim codes, or screenshots
that reveal them. Keep scripts and configuration changes in the code repo on a
task branch; link the PR from the report. If no code change was needed, say so.
